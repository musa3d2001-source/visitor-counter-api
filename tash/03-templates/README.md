# قوالب طشّ — `03-templates`

نظام قوالب لحساب **@tash.creative.kw**: كل قالب صفحة HTML تقرا بياناتها من ملف JSON، وسكربت واحد يطلّعها صورة PNG بالمقاس الصح.
تغيّر النص بالـJSON، تشغّل أمر واحد، وتطلع لك الصورة. ما في فوتوشوب، وما في نص مرسوم كصورة: الخط يتشكّل من Chromium بخطوطنا (OFL).

نظرة سريعة على كل الأمثلة: `examples/_overview.png` · المناطق الآمنة: `examples/safe-zones.png`

---

## ١. أسرع طريقة: عدّل وطلّع

كل الأوامر من داخل مجلد `tash/`:

</div>

```bash
# قالب + بيانات → صورة
node 03-templates/render.mjs 03-templates/templates/post-statement.html 03-templates/data/post-statement-01.json 03-templates/examples/my-post.png

# نفس الشي مع خطوط المناطق الآمنة (للمراجعة فقط، لا تنشرها)
node 03-templates/render.mjs 03-templates/templates/reel-cover.html 03-templates/data/reel-cover-launch.json review/<اسمك>/cover-guide.png --guide

# كل الأمثلة مرة وحدة (من examples.json) — أو جزء منها
node 03-templates/render.mjs --all
node 03-templates/render.mjs --all --only carousel
```

<div dir="rtl">

**الخطوات:**
1. انسخ ملف بيانات قريب من اللي تبيه من `data/` وسمّه اسم جديد.
2. غيّر النصوص (والصورة إذا فيه). لا تلمس ملف القالب نفسه.
3. شغّل الأمر. السكربت ينتظر الخطوط والصور، يطلّع الـPNG، ويطبع النتيجة، ومعها أي تحذير وسببه.
4. افتح الصورة بحجمها الكامل، وصغّرها لـ25% (حجم الشبكة) وشوف إذا تنقرا.

**معاينة حيّة بالمتصفح** (يحتاج سيرفر يخدم `tash/` كجذر، مثل اللي يشغّله السكربت):
`/03-templates/templates/post-cta.html?data=/03-templates/data/post-cta-01.json` — وأضف `&guide` للخطوط، أو `&slide=2` لشريحة معيّنة.

## ٢. شلون تكتب النص بالـJSON

| تكتب | يطلع | ملاحظة |
|---|---|---|
| `\n` | سطر جديد | قسّم السطور بالمعنى، مو بالطول. إذا حطيت `\n` القالب يلتزم بعدد سطورك ويصغّر الخط لين يركب. |
| `•••` | النقاط الثلاث (ليموني على الحبر) | «النقاط» علامة طشّ. مرّة وحدة بالتصميم، مكان «…». |
| `*كلمة*` | الكلمة باللون المميّز | ليموني على الحبر فقط. على الورقي والليموني تطلع حبر. كلمة وحدة بالتصميم، مو بكل عنوان. |
| أرقام وإنجليزي | تنعزل تلقائياً LTR | `3D`، `0.350`، `1080×1920` تطلع صح داخل الجملة العربية، والنقطة والنقطتين تبقى على الجهة العربية. |

- **الأسعار بالدينار:** ثلاث خانات عشرية: `0.350` مع «د.ك».
- **الأرقام:** اختار هندي (٢) أو عربي (2) وثبّت عليه بنفس التصميم. لوحات المونو (`CONCEPT AD — 01`) دايماً لاتيني.
- **ممنوع** تكتب عربي بخانة `slate` أو `series` (خط المونو ما فيه عربي، والتباعد يكسّر الحروف). السكربت يحذّرك إذا صار.
- اقرا كل سطر مرتين: الهمزة، ة/ه، الشدّة، وجهة علامات الترقيم (، ؟ !).

**ملاحظات على كل قالب:**
- **الجملة:** العنوان يصغر تلقائياً لين يركب بعدد السطور اللي كتبتها. الردّ (`reply`) سطر قصير هادي تحت. شعار طشّ دايماً تحت يسار (نهاية القراءة بالعربي) بكل بوست وشريحة.
- **الخدمة:** الصورة فوق لازم تكون شغل حقيقي من عندنا. إذا كانت من إعلان تجريبي، `concept` **إلزامي**.
- **قبل ← بعد:** الصورتين لازم نفس الكاميرا ونفس الكادر (مثل لقطات `bts` بـ`assets/`)، عشان القسمة تبين شي واحد نصّه قبل ونصّه بعد. `focus` = النقطة اللي تبيها بالنص (بكسلات الصورة الأصلية)، `scale` = حجمها.
- **«اطلب إعلانك»:** المحادثة نفسها هي الفكرة: رسالتك يسار، وفقاعتنا تكتب يمين. لا تكتب أسماء أو أرقام بالفقاعة.
- **الكاروسيل:** العدّاد مونو (`02 / 06`)، والنقاط الثلاث تتعبّى ليموني من اليمين لليسار مع التقدّم: الغلاف نص نقطة، والأخيرة الثلاث كاملة. الشرائح بالترتيب حسب مكانها بـ`slides`.
- **غلاف الريل:** `launch` = الشعار هو الصورة · `concept` = لقطة الإعلان + بطاقة «سليت» حبر فيها العنوان والتصنيف · `bts` = الهيكل، وشريط يبين اللقطة النهائية بين خطّين ليموني.
- **سؤال/تصويت:** بالـ`poll` نخلي مكان الملصق فاضي (يبين بـ`--guide`)، وتحطّه إنت بإنستغرام بنفس المكان.
- **الهايلايت:** الليموني بس على «شلون تطلب؟» (هي الفعل). الأسماء تنكتب بإنستغرام، مو على الصورة. ملف `06-copy/instagram-profile.md` يقترح «شغلنا» بدال «أعمالنا»: غيّرها بـ`data/highlights.json` إذا اعتمدناها.
- **بوستر العميل:** بألوان العميل وخطّه، مو ألواننا. طشّ يطلع بس بشريط «CONCEPT AD» تحت. إذا ما في صورة منتج، القالب يرسم علبة مؤقتة ومكتوب عليها `PRODUCT PLACEHOLDER` — بدّلها بـ`product.src` (صورة PNG شفافة أو رندر 3D).

## ٥. التحذيرات وشنو تسوي

| التحذير | يعني | الحل |
|---|---|---|
| `TEXT DOES NOT FIT` | النص ما ركب حتى بأصغر حجم مسموح | قصّر النص. لا تصغّر الحد الأدنى. |
| `text at minimum size` | ركب، بس بأصغر حجم | يفضّل تقصّره |
| `KEY CONTENT OUTSIDE SAFE AREA` / `UNDER THE REELS ACTION RAIL` | شي مهم بمكان تغطيه الواجهة أو القصّة | قصّر أو غيّر التقسيم |
| `OVERLAP` | نصّين فوق بعض | قصّر النص أو قلّل السطور |
| `TEXT OFF CANVAS` | نص طالع برّا الصورة | نفس الشي |
| `ARABIC IN A MONO SLATE` | عربي بخانة المونو | خله لاتيني، أو انقله لخانة عربية |
| `FONTS NOT LOADED` | خط ما انحمّل | تأكد إنك تشغّل من `tash/` وإن `_system/fonts` موجود |

## ٦. الستوري المتحرّك

`motion/story-new-work/` — صفحة واحدة، كل شي فيها دالة من الوقت (ما في CSS animation ولا `Math.random`).
التوقيتات كلها بـ`cues.json`، والصوت (`audio.py`) يقرا نفس الملف، فإذا غيّرت توقيت يتغيّر الاثنين.

</div>

```bash
# 1) الصوت (أصلي من tashaudio، −14 LUFS)
python3 03-templates/motion/story-new-work/audio.py
# 2) لقطات للمراجعة أول
node _system/tools/render.mjs --page 03-templates/motion/story-new-work/index.html --stills 0.5,1.7,2.2,6.9 --stills-dir review/<اسمك>
# 3) الفيديو (لا تزيد عن --workers 2: الجهاز مشترك)
node _system/tools/render.mjs --page 03-templates/motion/story-new-work/index.html --out 03-templates/examples/story-new-work-anim.mp4 --audio 03-templates/motion/story-new-work/audio.wav --workers 2
# 4) الفحص
bash _system/tools/contact.sh 03-templates/examples/story-new-work-anim.mp4 03-templates/examples/story-new-work-anim-contact.png
bash _system/tools/audio-check.sh 03-templates/examples/story-new-work-anim.mp4 review/<اسمك>/spec.png
```

<div dir="rtl">

- لعمل جديد: انسخ `data/story-new-work-01.json`، غيّر الصورة والنصوص، ومرّر الملف للصفحة: `--page "03-templates/motion/story-new-work/index.html?data=/03-templates/data/<ملفك>.json"`.
- القصة: فقاعة تكتب + «شغل جديد» ← النقاط تكبر وتمسح الشاشة (مرة وحدة بالقطعة) ← ترجع تصغر وتطير لين تصير «…» العنوان، وتبين الشغل ← السطر كلمة كلمة ← الاسم ← توقيع طشّ ← النقاط تكتب مرة أخيرة.
- الصوت: تكّات الكتابة ← سكتة قبل المسح ← ضربة وحدة على القطع ← ثلاث تكّات لما النقاط توصل ← إيقاع خليجي خفيف (مرواس وتصفيق) ينخفض وقت قراية السطر ← جرس يقفل على «ري» (بياتي).

## ٨. ملفات وأصول

- `src/tpl.js` — المحرّك المشترك: قراءة البيانات، النص الغني، تصغير الخط لين يركب، فقاعات المحادثة، النقاط، الشعار، الحبيبات (grain)، خطوط `--guide`، وفحوص المناطق والتداخل.
- `src/icons.js` — أيقونات هندسية بنسب النقاط في الشعار (القطر : المسافة = 1 : 0.178).
- `src/base.css` — أدوار الخطوط (Alexandria للعناوين، IBM Plex Sans Arabic للنص، JetBrains Mono للوحات، Archivo للاتيني).
- `assets/layl-bts-*.png` — لقطات مستخرجة من `05-concept-ads/01-perfume-layl/bts/` (شغل فريق الإعلانات التجريبية).
- صور «ليل» و«ستاك برجر» بالأمثلة تُقرا مباشرة من `05-concept-ads/` — إذا انعادت، الأمثلة تتحدّث بإعادة التشغيل.
- «لومة / LOOMA» علامة خيالية سويناها للمثال فقط (صودا لومي)؛ مكتوب عليها مثال وإعلان تجريبي.
- النصوص مأخوذة أو مبنية على `06-copy/` و`07-ops/05-process-and-timeline.md` (الخطوات الأربع).
