# Voiceover options (optional, Kuwaiti)

The current cuts are **music plus on-screen text only**. These lines are for later, if the owner wants to record a real human voice.
Each ad gets 2–3 options, from fullest to most minimal. **Less is usually better:** the music and type already carry the piece.

## Rules for every option
1. **The hook (first 1.5 s):** the voice either says exactly the on-screen words or stays silent. Never two different messages at once.
2. **Same words when they overlap.** If the voice and the screen say the same line, they match word for word.
3. **No voice over the sting or the `CONCEPT AD` slate.** The sonic logo and «إعلان تجريبي — علامة خيالية» get the last seconds to themselves.
4. **If a line doesn't fit, cut words.** Don't speed up. Calm Kuwaiti VO runs about 2–2.5 words per second; energetic is about 3.
5. **Concept ads speak in the client's voice, not ours.** Our tagline («يسولفون عنك») stays out of HABBA, STAKK and LAYL.

## LAUNCH AD (طشّ)

Structure: hook «هذا منتجك. / وهذا إعلانه.» → capability montage → process → chat bubbles «منو مسوي هالإعلان؟» → sting → CTA «عندك مشروع؟ خلّ إعلانك علينا.»
**Voice:** a confident Kuwaiti voice, dry wit, mid-pace, a slight smile. Male or female both work. Mic at a normal close distance; not a "trailer voice".

<div dir="rtl">

**خيار أ — «الواثق»** (~١٧ كلمة)

| المقطع | الصوت |
|---|---|
| الهوك | «هذا منتجك.» … «وهذا إعلانه.» |
| المونتاج | «فيديو. ريلز. تصميم. موشن.» (كلمة مع كل قطع — بس إذا القطعات 0.6 ث أو أكثر) |
| الخطوات | «من فكرة… لسكربت… لإعلان.» |
| الفقاعات | (سكوت — صوت الكتابة يكفي) |
| الستنق | (سكوت — اللوقو الصوتي) |
| النهاية | «عندك مشروع؟ خلّ إعلانك علينا.» |

**خيار ب — «السالفة»** (~٢٦ كلمة، أدفى)

| المقطع | الصوت |
|---|---|
| الهوك | «هذا منتجك…» «وهذا إعلانه.» |
| المونتاج | «كل منتج عنده سالفة… بس مو كل إعلان يعرف يقولها.» |
| الخطوات | «إحنا نكتبها… نرسمها… ونطلّعها إعلان.» |
| الفقاعات | «وبعدها؟» … (الفقاعات تكمّل) … «يسولفون.» |
| الستنق | (سكوت) |
| النهاية | «عندك مشروع؟ خلّ إعلانك علينا.» |

**خيار ج — «سطرين بس»**
الهوك: «هذا منتجك… وهذا إعلانه.» — والباقي موسيقى — والنهاية: «عندك مشروع؟ خلّ إعلانك علينا.»

</div>

- «نرسمها» means the storyboard. It's true; don't change it to «نصوّرها» (we don't film on location).
- If the owner wants the name spoken, say «طشّ.» once, dry, **after** the sonic logo's last hit, never over it.

## LAYL «ليل» No.07: perfume (concept)

Locked timings from `05-concept-ads/01-perfume-layl/src/shots.js` (80 BPM, 1 beat = 0.75 s):
S1 0.00 light sweep · S2 1.50 amber liquid · S3 3.00 gold-dust orbit · S4 6.00 atomiser (**spray 6.30**) · S5 8.25 text beat, mist lingers · S6 10.50 hero · end card 12.00 · lights out 13.20 · **sting 13.50–15.90**.
**Voice:** low, intimate, slow; close mic (15–20 cm) with gentle proximity. Breathy but not ASMR. Alto or baritone. Every pause is part of the read.

<div dir="rtl">

**خيار أ — «الأثر»** (~١٤ كلمة)

| الوقت (ث) | الصوت |
|---|---|
| 1.50–3.00 (S2) | «فيه ناس… تمشي.» |
| 3.00–6.00 (S3) | «وريحتهم… تكمّل عنهم.» |
| 6.30 (الرشّة) | (سكوت — خلّ الرذاذ يتكلم) |
| 8.25–10.50 (S5) | «عطر يبقى… بعد ما تمشي.» (نفس نص الشاشة، بنفس اللحظة) |
| 12.00 (البطاقة) | «ليل.» … «نمبر سڤن.» |
| 13.20 ← النهاية | (سكوت — الليل يطيح، والستنق) |

**خيار ب — «إنت»** (~١٣ كلمة)

| الوقت (ث) | الصوت |
|---|---|
| 1.50–6.00 | «طلعت من المكان…» |
| بعد الرشّة ~6.80 | «…بس ريحتك للحين هني.» |
| 8.25–10.50 | «عطر يبقى… بعد ما تمشي.» |
| 12.00 | «ليل.» |

**خيار ج — «الهمس»** (٣ كلمات)
S5: «تمشي… ويبقى.» — البطاقة: «ليل.»

</div>

- «No.07»: read «نمبر سڤن» (English, soft) or «سبعة». Pick one. The English read feels more like perfume branding. Don't say «رقم سبعة»; it sounds like a queue ticket.
- «يبقى» is naturally «يِبْگى» in Kuwaiti. For a pan-Gulf luxury feel the «ق» is acceptable. Choose once and keep it for the whole read.

## STAKK «ستاك برجر»: smash burgers (concept)

Timings aren't locked yet. Map each line to the cut's sections: hook → layers build → hero → end card → sting.
**Voice:** energetic, warm, smiling, *on the beat*. A little grit is fine. Mic close, mid presence.

<div dir="rtl">

**خيار أ — «الطبقات»** (كلمة مع كل طبقة)

| المقطع | الصوت |
|---|---|
| كل طبقة تنزل | «خبز.» «لحم.» «جبن.» … «سالفة.» |
| الهيرو | «ستاك برجر.» |
| البطاقة | «كل طبقة لها سالفة.» |

**خيار ب — «السالفة كلها»**

| المقطع | الصوت |
|---|---|
| الهوك | «تبي تسمع السالفة؟» |
| البناء | «من أول طبقة…» «لين آخر طبقة.» |
| الهيرو | «تبي السالفة كلّها؟» … «كُلها.» |
| البطاقة | «ستاك برجر — كل طبقة لها سالفة.» |

**خيار ج — «الصاج»** (الصوت يبدأ متأخر)
خلّ صوت الصاج يفتح الإعلان بدون كلام. أول كلام عند الهيرو: «سماش… على الصاج.» — والبطاقة: «ستاك برجر. كل طبقة لها سالفة.»

</div>

- Option A's words have to match the real layers in the cut. Change «خبز / لحم / جبن» to whatever is actually shown. **Never use «عيش» for the bun.** In Kuwait «عيش» means rice.
- Option B's pun: «كلّها» (all of it) / «كُلها» (eat it). Leave a half-beat between them so the twist lands.
- «طبقة» is naturally «طبگة», and «برجر» as Kuwaitis say it.

Timings aren't locked yet. Expected sections: opening → pour / brew → sip → hero → end card → sting.
**Voice:** calm, warm, a morning voice with a relaxed smile. Pauses longer than feels natural; that is the idea («على مهلك»).

<div dir="rtl">

**خيار أ — «الصبح»** (~٨ كلمات)

| المقطع | الصوت |
|---|---|
| الافتتاح | «الصبح… ما يحب العجلة.» |
| الهيرو | «حبّة.» |
| البطاقة | «قهوتك… على مهلك.» |

| المقطع | الصوت |
|---|---|

| الصب / الرشفة | «خذ نفس.» … «خذ رشفة.» |

## Recording & mix notes
- **Talent:** a native Kuwaiti speaker and a real person, with a signed release. No imitating a known voice, and no AI cloning of the talent's voice without separate written consent (see `07-ops/08-usage-rights.md` §5, §8).
- **Recording:** 48 kHz / 24-bit WAV, a quiet treated room, cardioid mic at 15–20 cm, pop filter. Record 3 takes per line (straight / warmer / drier) and 1 s of room tone at the start. One file per line: `VO_[AD]_[LINE]_t[n].wav`.
- **Mix:** duck the music 4–8 dB under the voice (`duck_curve` in `_system/audio`). Final ≈ −14 LUFS integrated, true peak ≤ −1 dBTP. Re-check with `_system/tools/audio-check.sh`.
- **Before you book anyone:** read each option aloud over the actual cut with a stopwatch. If it doesn't breathe, choose the shorter option.
