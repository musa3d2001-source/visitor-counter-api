# CTA & hook bank

58 ready lines in Kuwaiti dialect, grouped by where they're used.
**Public copy** (reels, captions, end cards) talks to one person: «عندك مشروع؟».
**DMs** use the plural by default (حيّاكم، تبون), following `07-ops/01-welcome-and-quick-replies.md`, because most messages come from business accounts. Mirror the person if they write in the singular.
Nothing below promises views, sales, speed or a price. `[[…]]` = placeholder.

## 1. Reel hooks: on screen in the first 1.5 s (≤ 6 words)

| # | الهوك | ينفع لـ |
|---|---|---|
| ١ | هذا منتجك. وهذا إعلانه. | إعلان الإطلاق، أي قبل/بعد |
| ٢ | لا تطوّف… شوف الفرق. | قبل/بعد |
| ٣ | إعلانك يبيله سالفة. | فكرة إعلان في ٣٠ ثانية |
| ٤ | مشروعك حلو… بس محد يسولف عنه؟ | ريل تعريفي |
| ٥ | العطر ما ينشاف. شلون نعلن عنه؟ | «ليل» وأي منتج صعب ينصوّر |
| ٦ | إعلان أكل؟ لازم يجوّع. | «ستاك برجر» ومطاعم |
| ٧ | هالإعلان بدأ بخربشة. | ورا الكواليس |
| ٨ | قبل لا يلمع… كان خطوط. | ورا الكواليس (3D) |
| ٩ | صورة جوال ← إعلان. | قبل/بعد |
| ١٠ | فكرة إعلان في ٣٠ ثانية. | السلسلة |
| ١١ | منو مسوي هالإعلان؟ | تيزر، أو ردّ على كومنت |
| ١٢ | نفس المنتج… إعلان ثاني. | قبل/بعد |
| ١٣ | جملة وحدة تبيع… أو تطفّش. | قولها بالكويتي |
| ١٤ | ما مسكتهم أول ثانية؟ راحوا. | أي ريل عن الهوك |
| ١٥ | عندك مشروع؟ هذا لك. | ريل خدمات |

</div>

«لا تطوّف» = don't scroll past (Kuwaiti «طوّف»). «تطفّش» = puts people off.

## 2. Story stickers

<div dir="rtl">

**تصويت (Poll)**
- «إعلانك الجاي: هادي ولا حماس؟» — «هادي» / «حماس»
- «تحب الإعلان: فيه كلام… ولا بس موسيقى؟» — «كلام» / «موسيقى»
- «أي غلاف أحلى؟» — «هذا» / «ذاك» (لمّا نعرض خيارين حقيقيين من شغلنا)
- «تشوف الإعلان قبل… ولا السعر قبل؟» — «الإعلان» / «السعر»

**اختبار (Quiz)**
- «شنو لازم يبين أول ثانية بالإعلان؟» — «الشعار» / «السعر» / «اللقطة اللي توقّفك» ✓
  - الإطار اللي بعده: «الشعار مكانه بالآخر. أول ثانية حق اللقطة اللي توقّفك.»

**سؤال (Question box)**
- «اسألنا أي شي عن الإعلانات.»
- «شنو مشروعك؟ اكتبه… ويمكن يكون فكرة الإعلان الجاية في ٣٠ ثانية.»

**سلايدر**
- «شكثر تبي هالإعلان حق مشروعك؟»

**رابط (Link)**
- «اطلب إعلانك» ← الواتساب
- «شلون تطلب؟» ← البوست المثبّت

**عدّ تنازلي (Countdown)**
- «إعلان طشّ ينزل…» (يوم الإطلاق بس)

**مشاركة**
- «دزّ هالستوري لصاحبك اللي فاتح مشروع.»

</div>

## 3. DM nudges

Full replies (`/hala`, `/price`, `/time`, `/accounts`, `/guarantee`, `/no`, follow-ups) live in `07-ops/01-welcome-and-quick-replies.md`. Use these short lines to open or move a conversation along. One emoji at most.

<div dir="rtl">

| الموقف | السطر |
|---|---|
| ردّ على ستوري أو تفاعل على إعلان تجريبي | «هلا والله، نوّرتونا 🙌 عاجبكم؟ إذا عندكم مشروع وتبون مثله، قولوا لنا شنو تبيعون.» |
| «ما عندي فكرة» | «عادي ترا — الفكرة شغلنا. بس قولوا لنا: شنو تبيعون، ومنو يشتري منكم؟» |
| دزّوا صورة منتج | «وصلت! نشوفها ونرجع لكم بشنو ممكن نسوي فيها.» |
| يترددون بسبب الميزانية | «نقدر نضبط الباقة على ميزانيتكم — نقلّل المخرجات، مو الجودة.» |
| «تضمنون مشاهدات؟» (مختصر `/guarantee`) | «بصراحة لا — محد يقدر يضمنها. اللي نلتزم فيه: الفكرة، والجودة، والموعد.» |
| طلب خارج خدماتنا (مختصر `/no`) | «هذي مو من خدماتنا — إحنا نسوي الإعلان نفسه بس. وإذا احتجتوه، حيّاكم.» |
| يبي يشوف نماذج | «كل شغلنا بالحساب. وللأمانة: أغلبه إعلانات تجريبية لعلامات خيالية — مكتوب عليها — عشان تشوفون مستوانا قبل لا تطلبون.» |
| سكتوا بعد السعر (مرة وحدة بس) | «هلا مرة ثانية 👋 للحين الفكرة في بالكم؟ إذا تبون نكمل، إحنا هني.» |

</div>

## 6. Caption CTAs (last line)

<div dir="rtl">

| # | السطر |
|---|---|
| ١ | دزّ لنا بالخاص ••• |
| ٢ | الخاص مفتوح، أو الواتساب من الرابط بالبايو ••• |
| ٣ | خلّ إعلانك علينا ••• |
| ٤ | تبي مثله لمشروعك؟ قول لنا شنو تبيع ••• |
| ٥ | احفظه لين تحتاجه. |
| ٦ | منشن صاحب مشروع يستاهل إعلان زين. |
| ٧ | شنو نوع مشروعك؟ اكتبه بالتعليقات… يمكن يكون الفكرة الجاية. |
| ٨ | عندك صورة منتج عادية؟ دزّها لنا، ونقول لك شنو نقدر نسوي فيها ••• |
| ٩ | شاركه مع شريكك بالمشروع. |
| ١٠ | الإعلان علينا… والسوالف عليهم. |

</div>

- Line ٧ only goes on «فكرة إعلان في ٣٠ ثانية» posts, and only if we really do pick from the comments.
- Line ١٠ is the brand idea as a sign-off. Use it sparingly, about once a month.
- Avoid «اكتب "أبي" بالتعليقات ونكلمك» until someone is actually ready to follow up every comment the same day.
