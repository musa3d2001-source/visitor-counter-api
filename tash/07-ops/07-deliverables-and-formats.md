# 07 · المخرجات والمواصفات

## الفيديو — الملف الأساسي (Master)

| | المواصفات |
|---|---|
| الحاوية / الترميز | **MP4** · فيديو **H.264** (High profile) · `yuv420p` · ألوان BT.709 · `faststart` |
| المقاس | **1080×1920** (9:16 عمودي) |
| الإطارات | **30fps** ثابت |
| الصوت | **AAC** ستيريو · **48 kHz** · 256-320 kbps |
| مستوى الصوت | **≈ −14 LUFS** متكامل · True peak ≤ −1 dBTP |
| النص على الشاشة | داخل المنطقة الآمنة: 220px فوق و420px تحت فاضية من النص المهم، و72px من الجنبين |
| الجودة | دقة عالية للأرشيف والرفع — ما نضغط الملف عشان يصغر |

## نسخ إضافية (حسب الباقة أو كإضافة)

| النسخة | المقاس | للاستخدام |
|---|---|---|
| مربع 1:1 | 1080×1080 | بوست، بعض الإعلانات الممولة |
| عمودي 4:5 | 1080×1350 | بوست الفيد |
| أفقي 16:9 | 1920×1080 | يوتيوب، شاشات، عروض |
| نسخة مختصرة | نفس المقاس | 6-10 ثواني أو 15 ثانية |

كل نسخة **يُعاد توزيع عناصرها** للمقاس الجديد — مو قص عشوائي من النسخة العمودية.

## التصاميم الثابتة

| | المواصفات |
|---|---|
| البوستر | **PNG** (الأصل، sRGB) + **JPG** جودة عالية (للإرسال السريع) |
| المقاسات | 4:5 = 1080×1350 · 9:16 = 1080×1920 · 1:1 = 1080×1080 |
| غلاف الريل | 1080×1920 JPG — العنوان في **الوسط** عشان يبان كامل لما ينقص في شبكة الحساب |
| للطباعة | مو مشمولة. ملف طباعة (CMYK، مقاس محدد، هوامش قص) عند الطلب *(قرار المالك: هل نقدمه وبكم؟)* |

## الترجمة النصية (اختياري)

- ملف **`.srt`** بترميز UTF-8، عربي (أو إنجليزي عند الطلب)، مطابق للتوقيت.
- مشمول عند الطلب مع «ريل» و«إطلاق». ينرفع مع الفيديو في المنصات اللي تدعمه.

## تسمية الملفات

```
TASH_[CLIENT]_[PROJECT]_[DELIVERABLE]_[RATIO]_[LENGTH]_v[NN]_[YYYYMMDD].ext
```

| الجزء | القاعدة | مثال |
|---|---|---|
| `CLIENT` | كود العميل بالإنجليزي، حروف كبيرة، بدون مسافات | `CLIENTCODE` |
| `PROJECT` | اسم قصير للمشروع | `LAUNCH` · `RAMADAN` |
| `DELIVERABLE` | `AD` فيديو · `CUT` نسخة مختصرة · `POSTER` · `COVER` · `CAPTIONS` | `AD` |
| `RATIO` | `9x16` · `4x5` · `1x1` · `16x9` | `9x16` |
| `LENGTH` | للفيديو بس | `15s` · `30s` |
| `vNN` | رقم النسخة — يزيد مع كل جولة | `v03` |
| `YYYYMMDD` | تاريخ التصدير | `20261120` |

أمثلة (بكود عميل وهمي):

```
TASH_CLIENTCODE_LAUNCH_AD_9x16_30s_v03_20261120.mp4
TASH_CLIENTCODE_LAUNCH_CUT_9x16_15s_v02_20261120.mp4
TASH_CLIENTCODE_LAUNCH_POSTER_4x5_v02_20261120.png
TASH_CLIENTCODE_LAUNCH_COVER_9x16_v01_20261120.jpg
TASH_CLIENTCODE_LAUNCH_CAPTIONS_AR_30s_v01_20261120.srt
```

- **المعاينات** (قبل الدفعة الثانية) تاخذ لاحقة `_PREVIEW` وعلامة مائية ودقة أقل:
  `TASH_CLIENTCODE_LAUNCH_AD_9x16_30s_v01_20261115_PREVIEW.mp4`
- **بدون** مسافات أو حروف عربية في أسماء الملفات — عشان ما تخرب في التحميل بين الأجهزة.

## التسليم

- **Google Drive** (الأساس): مجلد باسم `TASH_[CLIENT]_[PROJECT]_FINAL` ← صلاحية **Viewer** لأي أحد عنده الرابط (أو لإيميل العميل).
- **WeTransfer** (بديل): روابطه **تنتهي بعد أيام** — قول للعميل يحمّل الملفات على طول.
- **لا نرسل الملف النهائي كمرفق بالدايركت** — الرسائل تضغط الفيديو وتخرب جودته (إلا كمعاينة سريعة). النهائي برابط، ونرسله بالإيميل.

ترتيب المجلد:

```
TASH_[CLIENT]_[PROJECT]_FINAL/
├── 01_VIDEO/       الفيديو الأساسي 9:16
├── 02_CUTS/        النسخ والمقاسات الإضافية
├── 03_DESIGNS/     البوسترات (PNG + JPG)
├── 04_COVER/       غلاف الريل
├── 05_CAPTIONS/    ملف .srt (إذا موجود)
└── READ-ME.txt     شلون تنشرون بأفضل جودة (نفس نصايح 09-delivery-message.md)
```

## الأرشفة

| شنو | كم نحتفظ فيه | ملاحظة |
|---|---|---|
| الملفات النهائية | **12 شهر** من التسليم *(قرار المالك)* | العميل يحتفظ بنسخته — بعد المدة ما نضمن نقدر نرجعها |
| ملفات المشروع المفتوحة (Source) | **12 شهر** *(قرار المالك)* | تبقى ملك طشّ — ما تنسلّم إلا باتفاق (`08-usage-rights.md`) |
| ملفات العميل (لوقو، صور، لقطات) | لين نهاية الأرشفة | ما نستخدمها في أي مشروع ثاني |
| المراسلات والاعتمادات (لقطات شاشة) | 12 شهر | مرجع لو صار خلاف |

بعد ما يتسكّر المشروع: انقل المجلد إلى `ARCHIVE/[YYYY]/[CLIENT]_[PROJECT]` وحدّث عمود `notes` في الـtracker بتاريخ الأرشفة.

## قبل التسليم — فحص سريع (5 دقايق)

- ☐ شغّلت الفيديو كامل من البداية للنهاية، بالصوت وبدونه.
- ☐ النصوص: مراجعة إملائية مرتين، علامات الترقيم العربية (، ؟ !) بمكانها، الأسعار والتواريخ **حرفياً** مثل ما أرسلها العميل.
- ☐ النص المهم داخل المنطقة الآمنة.
- ☐ الصوت: ≈ −14 LUFS، ما فيه تقطيع أو طقطقة، والنهاية ما تنقطع فجأة.
- ☐ المقاس والإطارات صح لكل نسخة.
- ☐ أسماء الملفات حسب القاعدة، وبدون `_PREVIEW`.
- ☐ الرابط يفتح من جهاز ثاني (مو بس من حسابنا).
