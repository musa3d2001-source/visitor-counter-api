# الأصول

> كل أصول اللعبة **أصلية بالكود**: هندسة وخامات وأصوات تُولَّد عند التشغيل. لا صور ولا نماذج ولا ملفات صوت خارجية، ولا خطوط إضافية. أي أصل خارجي يحتاج موافقة المالك ويُسجَّل هنا.

## 1. الرسوم (`src/game/render/`)

| الأصل | كيف يُولَّد | الملف |
|---|---|---|
| الخامات (ساج، جريد، حجر مرجاني، زجاج معشّق، صندوق ضوء، رمل) | رسم إجرائي على `canvas` بمولد ثابت البذرة، فالخامة نفسها في كل تشغيل | `render/effects.ts` |
| الزجاج المعشّق | شبكة معينات ودوائر بألوان مشبعة وخطوط رصاص داكنة (لا لون سماوي شاحب، حسب ملاحظة لجنة الحكم) | `effects.ts` (`stainedGlassTexture`) |
| القنديل | قفص نحاسي بتوهج دافئ؛ يصعد عند تحرره ويصير نجمة رباعية الرؤوس (لا رموز دينية أو وطنية) | `scene.ts`، `effects.ts` (`sparkleGeometry`) |
| الكتل | `RoundedBoxGeometry` بحواف مستديرة، وInstancedMesh لكل خامة | `scene.ts` |
| السماء والفجر | ثلاث محطات ألوان (ليل ← سَحَر ← شروق) تُمزج بتقدم تحرير القناديل، والقمر والشمس أقراص بهالة | `render/style.ts`، `effects.ts` |
| الجزيرة والبحر والنخيل والصخور والأفق | هندسة إجرائية مدموجة في draw call واحدة؛ الأفق كتل وقباب عامة لا معالم حقيقية | `scene.ts` |
| المرقاب | أنبوب بحلقات ذهبية على حامل ثلاثي فوق مصطبة مرصد (لا مدفع ولا مقلاع) | `scene.ts` |
| الشظايا والغبار والوهج | InstancedMesh واحدة للشظايا، ونظاما جسيمات بشيدر صغير؛ للعرض فقط | `effects.ts` |
| دليل التصويب | نقاط مستديرة بلون القذيفة، طولها من `rules/guidePoints` | `scene.ts` |

الهوية: «فانوس الخليج» (PLAN.md §2) على لوحة «الفصل المشمس» (كريمي، فيروزي، ذهبي). المحظور: الثيم الملكي، والقلاع، والتيجان، والمهرجانات، والطيور، والمقلاع، وأي معلم حقيقي أو رمز ديني أو وطني يُهدم.

## 2. الأصوات (`src/game/audio/sfx.ts`)

مؤثرات WebAudio إجرائية (مذبذبات جيبية ومثلثية وضجيج مرشَّح من مخزن واحد) بلا موسيقى افتراضيًا، ومع كتم:

| الصوت | الاستعمال | المدة |
|---|---|---|
| `launch` | الإطلاق | ≤ 0.6 ث |
| `impact-wood`، `impact-stone` | الاصطدام | ≤ 0.6 ث |
| `shatter-glass`، `crumble-frond`، `lightbox-burst` | الكسر حسب الخامة | ≤ 0.6 ث |
| `lantern-freed` | تحرر قنديل (رنين صاعد بخمس نغمات) | ≈ 1.1 ث |
| `splash` | سقوط في البحر | ≤ 0.6 ث |
| `correct`، `wrong` | الإجابة؛ الخاطئة نغمتان ناعمتان مشجعتان أخفض صوتًا، لا صفارة | ≤ 0.6 ث |
| `star`، `ui-tap` | النجمة واللمسات | ≤ 0.8 ث |

- النغمات من سلّم خماسي واحد فتتآلف عند التداخل.
- حد للاصطدامات (12 في الثانية على الأكثر، و24 صوتًا متزامنًا) فلا يتشوه الصوت في الانهيار الكبير.
- السياق الصوتي يُنشأ بعد أول لمسة (شرط Safari على iPhone)، ولا يُحفظ شيء؛ الصفحة تحفظ تفضيل الكتم.
